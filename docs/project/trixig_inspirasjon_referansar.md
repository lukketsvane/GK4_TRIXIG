# TRIXIG redesign — visuell research & inspirasjonskartlegging

**Brief:** Kome vekk frå "L"-pistolforma. Behalde dei to hovudkomponentane: éi battericelle (~18650, ø18×65 mm) og éin gearmotor med utgåande aksel (~ø25×60 mm). Plus PCB, trigger og retningsknapp.

**Domene for inspirasjon:** *hushaldsreidskap* (IKKJE verktøy/drillar). Prioritert: ikoniske / prisvinnande / historisk viktige design som løyser same arkitektoniske utfordring — å pakke ei sylindrisk celle og ein motor med aksel inn i ei hand-haldt form.

---

## Formarketypar — oversikt

```
A. WAND / STAV          — inline sylinder, motor + batteri ende-mot-ende
B. PALM / PEBBLE        — kompakt blob i handflata
C. OVOID / EGG          — avlangt egg, batteri og motor pakka tett
D. KOLONNE / TOTEM      — vertikal stabling, ofte med dock
E. BUE / KURVE          — organisk handgrip, ikkje 90°
F. RING / DONUT         — hol gjennom kroppen
G. TODELT / MODULÆR     — separat dock eller batteripakke
```

---

## A. WAND / STAV — *inline sylinder*

Den reinaste løysinga for to-komponent-arkitektur: legg motor og batteri ende-mot-ende. Resulterer i ei lang, slank stav. Ergonomisk lik ein tjukk penn.

| # | Referanse | Designar / år | Kvifor relevant |
|---|---|---|---|
| A1 | **Bamix M200** stavmiksar | Roger Perrinjaquet, 1954 (Sveits) | Definerer kategorien. Motor i topp, aksel i botn. Industriikon, framleis i produksjon uendra. |
| A2 | **Braun MR 30** håndmiksar | Braun Design Team (Rams-era), ~1976 | Streng tysk minimalisme. Sjå silinderbrot og knappplassering. |
| A3 | **Quip elektrisk tannbørste** | Simon Enever, 2015 | Cooper Hewitt-samlinga. Reduksjonistisk pen. Magnetisk dock. |
| A4 | **Philips Sonicare DiamondClean** | Philips Design, 2011 (Red Dot) | Slankt handtak, glas-dock. Premium-uttrykk i lågt volum. |
| A5 | **Foreo ISSA 2** | Foreo, 2014 | Silikonkledd stav. Mjuk-hard materialkontrast. |
| A6 | **Maglite Solitaire** | Anthony Maglica, 1988 | Single-cell-arketype. MoMA-samlinga. Knurla aluminium. |
| A7 | **Aerolatte mjølkeskumar** | Aerolatte, 2002 | Den enklaste mogelege wand. Eitt batteri, ein motor, ein knapp. |
| A8 | **Apple Pencil (2. gen)** | Apple, 2018 | Ergonomi for langvarig grep. Flat side mot rulling. |

**Søkeord til Figma:** `bamix classic`, `quip toothbrush product`, `sonicare diamondclean handle`, `maglite solitaire`, `aerolatte original`

## F. RING / DONUT — *hol gjennom kroppen*

| # | Referanse | Designar / år | Kvifor relevant |

| F1 | **Dyson Supersonic** | Jake Dyson, 2016 | Air Multiplier-ringen. Motor flytta til handtak for å gjere det mogeleg. |
| F2 | **Dyson Airwrap** | Dyson, 2018 | Sylindrisk kropp + skiftbare ringar. |
| F3 | **B&O Beosound A1 / Edge** | Michael Anastassiades + Cecilie Manz | Disk- og ringformer i hushald. |
| F4 | **Loop wireless earbud case** (diverse) | — | Ringgrip-ergonomi. |
| F5 | **Apple HomePod mini** | Apple ID, 2020 | Kuleform med flat fot — for hyllereferanse. |

## Lateral / kuriøs — *push the brief*

Ting som ikkje passar nokon arketype men kan opne idéar:

- **Hario Smart G electric coffee grinder** — handsveiv-form med motor. Vertikal med trakt på toppen.
- **Vintage egg-piskar (manuell, krank)** — to-akse-ergonomi som L-en prøver å løyse.
- **Joseph Joseph foldable ladles** — sammenleggbart hushald. Foldable TRIXIG?
- **Braun HL 1/11 vifte** (Reinhold Weiss, 1961) — sirkulær motor, kompakt kropp. MoMA.
- **Alessi Anna G. korketrekkar** (Alessandro Mendini, 1994) — antropomorf hushaldsikon. Diskuter karakter.
- **Stelton Cylinda Line** (Arne Jacobsen, 1967) — modulært sylindersystem.
- **Joe Colombo Boby trolley** (1970) — modulær arkitektur, søyle med skuffer.

## Forslag til moodboard-struktur i Figma

```
Frame 1: BRIEF — Trixig dagens form + dei to komponentane (foto frå IKEA)
Frame 2: ARKETYPE A — wand     (3-5 referansar)
Frame 3: ARKETYPE B — palm     (3-5 referansar)
Frame 4: ARKETYPE C — ovoid    (3-5 referansar)
Frame 5: ARKETYPE D — kolonne  (3-5 referansar)
Frame 6: ARKETYPE E — bue      (3-5 referansar)
Frame 7: ARKETYPE F — ring     (2-3 referansar, retorisk)
Frame 8: DOCK / MODULÆR        (ramme på tvers — kan kombinerast med kva som helst over)
Frame 9: LATERAL — kuriøse hushald
Frame 10: SHORTLIST — 6-8 referansar du faktisk vil utvikle vidare
```

For kvar referanse: 1 hovudbilete + 1 detaljbilete + namn/designar/år + 1-setnings notat om *kva du tek med*.

## Neste steg når du har plassert bilete

Når moodboardet er fylt, kan eg hjelpe deg med:

1. **Komponent-pakkings-skissar** — vise korleis 18650 + gearmotor faktisk får plass i kvar arketype (volumstudie, ikkje CAD).
2. **Vekt- og tyngdepunkt-analyse** — kor handa må vere for at du ikkje bommar.
3. **Trykk- og ergonomi-vurdering** — kva arketypar tek best opp aksial reaksjonskraft når du skrur.
4. **Konsept-shortlist-evaluering** — pro/kontra-matrise mot brief.
